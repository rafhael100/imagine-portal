# F398 — Original Imagine visual identity in Laravel Portal

The first approved Node.js `portal.css` is the design reference. The Laravel demo previously rendered the main palette in dark blue. F398 restores the approved **Imagine orange #F9941D**, charcoal `#171b19`, soft neutral backgrounds and clean white sidebar with orange current-page emphasis. Existing component structures, headings and responsive mobile breakpoints are retained; no functional or permission change is introduced.

The Portal Blade brand now displays the existing original `assets/logo-imagine.png` (not a substitute text drawing). The development-only Docker build context already includes the repository root; it copies the same source PNG to `public/_development/branding/logo-imagine.png`. When working from a local checkout or VPS developer workspace, the isolated `infra/development/portal-demo/prepare-brand-assets.sh` performs the exact byte-for-byte copy without network access or extra dependency. The destination is gitignored because the authoritative source remains the original root asset.

The offline preview is **not** allowed to reference any same-origin or external asset. `DemoPortalStaticExporter` therefore reads the original PNG from the local repo (or the Docker-copied public file), verifies its PNG signature and bounded size and checks that both copies match if both exist. It embeds the PNG in each of the ten exported HTML pages using `data:image/png;base64,...`. The offline CSP is explicitly narrowed back to `img-src data:` before the existing `DemoPortalNavigationAudit`, making all eleven existing preview pages safe to open without a web server. The index inherits the same charcoal/orange palette.

This is a visual restoration only. The offline review navigation is clickable inside the generated files, while the actual Laravel client sidebar deliberately remains non-interactive. **No authentication, customer-specific routes, CRM operations, checkout, payment or production serving is enabled**: security issue #64 remains OPEN/NO-GO. The source logo is copied, not exported as a font or re-created. No merge to main, VPS/Cloudflare deployment or expense.

To prepare the asset in a local checkout: `bash infra/development/portal-demo/prepare-brand-assets.sh`. The existing `portal:demo-export` console command creates the read-only preview only in `APP_ENV=local/testing` (never a public page).
