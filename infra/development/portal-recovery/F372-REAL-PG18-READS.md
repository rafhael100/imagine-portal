# F372 — Actual restricted Portal SQL auth and grant readers behind F371 witness pre-/post-check

F372 adds two **non-operational** PHP infrastructure adapters in the real Portal tree. They call the existing `PortalBrowserAuthentication::isActiveBusinessSession` and `PostgresPortalPermissionPreflight::hasCandidateGrant` **only through** the F371 online signed-witness pre/post candidate. Business tenant for the grant check must match the server-pinned witness organization. Neither wrapper issues or revokes sessions or grants permissions.

A dedicated disposable PostgreSQL 18 GitHub Action installs the actual Laravel Portal identity schema, restricted runtime SQL roles and password/MFA ledger. The workflow uses only synthetic data to create a valid business-shaped session digest, then invokes the existing **real PostgreSQL restricted session adapter and permission preflight class** through F371/F372. The test covers a session observed active, no membership grants, invalid session/reference/permission/organization, signed witness mismatch, unavailable witness, forged signature, and durable revocation.

**Important:** The CI harness fabricates a correctly signed witness from an ephemeral signing key **in its own process**. It is not an independent online authority; this is strictly a wiring/integration test of existing SQL readers through the new negative-only fence. Both a matching witness and a SQL-positive session return only `LAB_READ_OBSERVED_STILL_NO_SERVING` with all authorization flags false. This cannot secure any user-facing route and does not replace the real external witness, token revocation propagation, mandatory all-request gate, race-free authorization or security reviews. No routes are registered; CI checks that these names do not appear in route/bootstrap bindings.

**Next needed:** independently authenticated source, trustworthy publisher key custody/off-host persistence, online serving fence on *every* relevant request, atomic cross-service fencing, and recovery runbooks. Issue #64 remains OPEN/NO-GO for public serving and real VPS recovery.
